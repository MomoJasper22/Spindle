**1: USER MANAGEMENT**

**Main Functions**

* Add User  
* View User  
* Update User  
* Delete User  
* Manage User Roles

**Transactions**

| Transaction | Description |
| ----- | ----- |
| User Registration | Creates a new user account. |
| User Login | Allows an authorized user to access the system. |
| Update User | Modifies user account information. |
| Change Password | Allows users to change their password. |
| Deactivate User | Disables an existing user account. |

**5: TRANSACTION** 

**Purpose**

The Transaction Module manages the main business or operational transactions of the proposed system.

**Main Functions**

* Create Transaction  
* View Transaction  
* Update Transaction  
* Cancel Transaction  
* Search Transaction

**Transactions**

| Transaction | Description |
| ----- | ----- |
| Create Transaction | Records a new transaction. |
| View Transaction | Displays transaction details. |
| Update Transaction | Modifies transaction information when permitted. |
| Cancel Transaction | Cancels an existing transaction. |
| Search Transaction | Searches for previous transactions. |

**Note:** The actual transaction should depend on the proposed system.

Examples:

* Student System → Enrollment Transaction  
* Clinic System → Consultation Transaction  
* Inventory System → Stock-In/Stock-Out Transaction  
* Reservation System → Reservation Transaction  
* Sales System → Sales Transaction  
* Library System → Borrowing/Returning Transaction
